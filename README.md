# Pherka
기억을 바꾸는 여정 속에서, 다시 나아갈 용기를 찾는 이야기.

《Pherka》는 실패와 후회가 남아 있는 기억 속 공간을 탐색하고, 주변의 사물과 사건을 재구성하며 이야기를 진행하는 **2D 탑다운 내러티브 퍼즐 게임**입니다.

플레이어는 영혼들이 머무는 ‘쉼터’의 관리자 하달이 되어, 조력자 모사와 함께 영혼 페르카의 기억 속으로 들어갑니다. 집과 학교, 그리고 일기 속에 남겨진 장면들을 돌아보며, 한 사람의 마음에 오래 남아 있던 순간들을 마주하게 됩니다.

작은 실수, 전하지 못한 말, 뜻대로 이루어지지 않은 결과. 하달은 기억 속 상황을 바꾸어 페르카가 겪었던 실패를 막으려 합니다. 하지만 기억을 고치는 일이 이어질수록, 모사의 질문은 하달이 당연하게 여겼던 업무의 의미를 흔들기 시작합니다.

**당신은 기억 속에 무엇을 남기게 될까요?**

*본 게임에는 골드메탈(GoldMetal)의 무료 에셋 「TopDown 2D RPG BE3」와 TTRM의 배경음악이 사용되었습니다. 각 에셋과 음원의 저작권은 해당 제작자에게 있으며, 창작에 도움이 되는 자료를 제공해 주신 제작자분들께 감사드립니다.*
